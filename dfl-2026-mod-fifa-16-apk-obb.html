Installation Guide — Three Parts Required

This mod requires APK, OBB, and Data folders. Follow these steps carefully:

Step 1: Download all files using the button below (approx 2.1 GB).
Step 2: Enable "Install from unknown sources" in Settings > Security.
Step 3: Install the APK — do NOT open the game yet!
Step 4: Extract the OBB folder and copy it to Internal Storage/Android/obb/com.dfl.fifa16.mod.
Step 5: Extract the Data folder and copy it to Internal Storage/Android/data/com.dfl.fifa16.mod.
Step 6: Launch the game. First boot takes 2-3 minutes.
Step 7: Start a Career Mode with any Bundesliga club and enjoy.

Pro Tips From the DFL Community:
